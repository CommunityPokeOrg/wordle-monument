## The Shrine

`index.html` + `main.js` — an interactive 3D retro-browser shrine (Three.js, no build step). Open `index.html` or serve the directory statically:

```
python3 -m http.server 8000
```

Features: a stone obelisk under a phosphor CRT glow, the WRIST tile crown, orbiting Game 11 guess rows (SPADE → RUSTY → TRUST → WRIST), the sacred golden PENIS opener, a rotating halo of the full title, and the Taylor C602 pulley-equity ledger. Drag to orbit, scroll to zoom, click the floating tile rows for their inscriptions.

This is a playful memorial — carved in jest, maintained with pride.
